# Changelog

## 0.2.1

- Cleaner top bar: one centered row with a search icon, Clipboard, your categories as colored dots, and +
- Start typing anywhere on the shelf to search; Esc clears the search, then closes it
- Type filter (Text, Links, Images, Files) moved into the search field
- Pinned tab appears only when something is pinned; Pause and Settings live in the menu bar menu
- Empty search results say so instead of suggesting you copy something

## 0.2.0

- New shelf interface: history slides up from the bottom of the screen as a horizontal row of large cards
- Categories: create color-coded categories, add cards to them, rename, recolor or delete them
- Pinned items and each type (Text, Links, Images, Files) have their own tabs
- Keyboard navigation: ← → between cards, Return to paste, Esc to back out
- Cards show a colored header, source app, and details like character count, link host or image size
- The menu bar icon opens a menu (Open, Pause Capture, Settings, Quit)
- Items in a category are kept like pinned items
- Existing 0.1.0 history is migrated automatically

## 0.1.0

First release.

- Menu bar clipboard history for text, links, images and files
- Card grid with search, type filters, pinning and click-to-copy
- ⇧⌘V floating panel over any app, with a customizable shortcut
- Optional auto-paste into the current app (needs Accessibility)
- Instant QR Share for links and short text
- Ignored apps (password managers by default), Pause, and auto-delete after a day, week or month
- History size from 100 to 2,500 items; launch at login
- iCloud sync support for builds signed with an Apple Developer profile
